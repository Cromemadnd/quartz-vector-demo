这里集中展示本地开发版皮肤的各项功能。所有示例都使用普通 Markdown 和文章头部的 YAML，方便复制到自己的站点。

## 内容组件

- [信息框：星海图书馆](features/infobox)：图片、双语名称、分组资料和深浅主题色。
- [Starsea Library — English](features/infobox-en)：图书馆的英文版本。
- [导航模板](features/navigation)：共享模板、文章内模板、默认折叠和当前页纯文本。
- [Markdown 排版](features/content)：段落、表格、引用、代码与底部分类。

## 阅读与导航

- [阅读布局](features/reading)：菜单固定、左右侧栏、字号、配色与页面宽度。
- [长目录与滚动按钮](features/long-page)：超过 28 个章节的目录、分节定位与跳到页首页尾。
- [无分节页面](features/no-sections)：没有章节时不显示目录。
- [搜索与预览](features/search)：标题与描述候选，以及带预览的全文搜索。
- 知识图谱：打开[信息框示例](features/infobox)，点击标题下方的「知识图谱」，查看示例文章之间的连接。

## 可以直接操作的地方

试着把主菜单和目录移到左侧，把探索移到右侧。右边的外观面板可以调整文字、宽度与主题。页面窄于 1120px 时，菜单统一改用按钮，正文两侧不再留侧栏空间。

[原来的首页排版测试](index)和 [Another article](another)仍然保留。页脚也换成了演示站自己的 Markdown 和链接。
