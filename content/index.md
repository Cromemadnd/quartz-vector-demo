This site demonstrates [quartz-skin-vector-2022](https://github.com/Copartiper/quartz-skin-vector-2022), a GPL-licensed adaptation of MediaWiki's Vector 2022 for the Quartz static site generator. Its interface is configured in English; both English and Chinese sample articles are available.

## Start here

- [English feature guide](features/index-en): an overview of the interface and interactive examples.
- [Starsea Library — English](features/infobox-en): a complete sample article with an infobox, sections, and navigation boxes.
- [星海图书馆 — 简体中文](features/infobox): the corresponding Chinese sample article.
- [中文功能导览](features/): the original Chinese feature guide.

## Explore the interface

Try the search field, contents panel, main menu, and appearance settings. Switch between light and dark themes and resize the window to inspect the responsive layout.

- [Navigation boxes](features/navigation) — Chinese explanatory text.
- [Long table of contents](features/long-page) — Chinese sample text.
- [Markdown formatting](features/formatting) — headings, lists, tables, and code.
